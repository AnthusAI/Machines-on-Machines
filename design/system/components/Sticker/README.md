The tilted pink brand tile that names the site on the home page and the section on section pages.

- **Provide**: an optional `subject` (the section name; omit it on the home page), a `tagline` (the site tagline with `taglineVariant="display"`, or a one-sentence section description with `taglineVariant="text"`), and one `Button` as children ("Steer the newsroom" or "Steer this section").
- **Placement**: in the right-hand column of the first grid row, pulled up about 150px so it overlaps the nav bar and runs off the top edge. Keep it clear of nav items and never over the lead story's text.
- It tilts by `sticker-tilt`; only it and the wordmark's seal tilt. Its backing is a solid `machine` block offset 16px, never a shadow.
- Use `flat` only where rotation would clip, such as a phone layout.
- One sticker per page. Never place one on article or wiki pages; those carry the `Spine`.
