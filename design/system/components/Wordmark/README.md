- Where a column limits the seal (the spine), shrink the whole wordmark rather than "on" alone.
- Use `subject` only for section and wiki naming; the site itself is always *Machines on Machines*.
- Do not recolor the seal: it is always `human` with `on-human` text, except inside the spine's section name, where it is `paper` with `ink`.
