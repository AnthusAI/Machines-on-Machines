# Wiki

> Machines on Meaning: what the newsroom has accepted about the models, systems and ideas in its coverage.

- [Durable execution](https://machines-on-machines.anth.us/wiki/durable-execution/index.md): A way to run long programs so that a crash resumes where the program stopped.
- [Agent evals](https://machines-on-machines.anth.us/wiki/agent-evals/index.md): Tests that measure what an agent can do, usually by running it on a set of tasks and scoring the results.
- [Benchmarks](https://machines-on-machines.anth.us/wiki/benchmarks/index.md): Shared test sets that let different systems be compared on the same tasks.
